## AI is smart enough already.<br>We make it good to use.

We explore new ways to live and work with intelligence.

### Galta — point at what you mean

A local-first AI canvas beside the web page you're browsing. Collect
references, sketch an idea, then work with Codex or Claude Code on the same
canvas. Results land beside the material that informed them.

[Explore Galta](https://galta.art/en/?utm_source=github&utm_medium=profile&utm_campaign=public-launch) ·
[Install the beta](https://galta.art/download/?utm_source=github&utm_medium=profile&utm_campaign=public-launch) ·
[Source · AGPL-3.0](https://github.com/aha-labs-hq/galta)

### Mochi — your project's context, in the group chat

A Mac companion that brings the GitHub projects you choose into Feishu and
Lark conversations. Get answers with sources, give decisions an Issue and an
owner, and return to the same work to check progress. Uses your own model account.

[Meet Mochi](https://mochi.host/?utm_source=github&utm_medium=profile&utm_campaign=public-launch) ·
[Download the beta](https://mochi.host/download/?utm_source=github&utm_medium=profile&utm_campaign=public-launch) ·
[Source · Apache-2.0](https://github.com/aha-labs-hq/mochi)

Both projects have public betas. Their download pages list current device
requirements and limitations. Mochi's interface is currently in Simplified Chinese.
