# Aha Labs on GitHub

The public profile for [Aha Labs](https://github.com/aha-labs-hq).

[`profile/README.md`](profile/README.md) appears on the organization's
Overview page. It introduces our work and links to the product websites.

## Maintaining the profile

- Keep the profile in English and consistent with [ahalabs.site](https://ahalabs.site/en/).
- Use only public product information. Product source, operational details,
  credentials, and private roadmap material belong in their own repositories.
- The artwork in `profile/assets/` is an unchanged copy of the published
  [brand assets](https://branding.ahalabs.site/en/). Update it from the branding
  source; do not redraw or edit the exported shapes here.
- Check the rendered organization page, image loading, and destination links
  after changing the profile. A commit on the default branch updates it.
